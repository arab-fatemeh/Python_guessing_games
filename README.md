# Python guessing games

My first Python exercises (2024).

- guess_age_game.py: guess my age, with "older/younger" hints and a try counter
- guess_game.py: guess the computer's number between 1 and 99
- guess_game_3.py: the computer guesses your number using binary search (at most 7 guesses)

Run with: python <file name>.py
